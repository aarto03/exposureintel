# exposureintel
Supply-chain vulnerability triage. Ranks SBOM findings by real-world exploitation risk.


# The Problem
Scanners like grype report hundreds of CVEs per project, and most of them don’t matter. Teams need to know which vulnerabilities are actually being exploited, which are reachable in their code, and what to fix first. Your tool takes a software bill of materials (SBOM) or a dependency file and outputs a ranked, evidence-backed remediation report.
