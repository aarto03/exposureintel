# Security Policy

## Reporting a vulnerability
Please open a private report via GitHub's "Report a vulnerability"
button on the Security tab (preferred) or email <your-email>.
Do not open a public issue for security problems.

## Scope
ExposureIntel parses untrusted SBOM and lockfile input and queries public
vulnerability APIs. Parser bugs, report-injection issues, and unsafe
handling of that input are in scope.

## Supported versions
Only the latest release receives fixes.
